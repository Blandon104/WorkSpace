# 🎤 My 90-Second Pitch in English

**Project:** RECORDATE — Academic Activity Reminder System  
**Estimated length:** about 185 words  
**Goal:** practice a clear presentation of my skills and my school project.

## 1. Complete pitch

Hi! Have you ever forgotten an important homework assignment or a school deadline? I want to help students stay organized and feel more confident.

My name is Alejandro, and I am a high school student from Medellín, Colombia. I am learning web development, and my goal is to become a software developer.

I work with HTML, CSS, JavaScript, and React to build web pages and interactive user interfaces. I also use GitHub to save my code, track changes, and collaborate on projects. I am learning how Supabase can provide a database and user authentication for web applications.

One of my projects is called RECORDATE. It is an academic activity reminder system designed to help students organize homework, deadlines, and school activities. The idea is to let users manage their tasks, set priorities, and remember important dates. I am developing this project with React and Vite, using Bootstrap to help design the interface. Supabase is planned for the database and authentication features.

I enjoy solving problems, learning new technologies, and improving my work step by step. I also understand that teamwork, communication, and responsibility are important when building software.

I am looking for opportunities to keep learning and gain experience as a developer. Thank you for your time! I would be happy to show you my project.

## 2. Traducción al español

¡Hola! ¿Alguna vez has olvidado una tarea importante o una fecha límite escolar? Quiero ayudar a los estudiantes a mantenerse organizados y sentirse más seguros.

Mi nombre es Alejandro y soy estudiante de secundaria de Medellín, Colombia. Estoy aprendiendo desarrollo web y mi objetivo es convertirme en desarrollador de software.

Trabajo con HTML, CSS, JavaScript y React para crear páginas web e interfaces interactivas. También uso GitHub para guardar mi código, registrar cambios y colaborar en proyectos. Estoy aprendiendo cómo Supabase puede proporcionar una base de datos y autenticación de usuarios para aplicaciones web.

Uno de mis proyectos se llama RECORDATE. Es un sistema de recordatorios de actividades académicas diseñado para ayudar a los estudiantes a organizar tareas, fechas límite y actividades escolares. La idea es permitir que los usuarios administren sus tareas, establezcan prioridades y recuerden fechas importantes. Estoy desarrollando este proyecto con React y Vite, y uso Bootstrap para ayudar a diseñar la interfaz. Se tiene previsto usar Supabase para la base de datos y las funciones de autenticación.

Disfruto resolver problemas, aprender nuevas tecnologías y mejorar mi trabajo paso a paso. También entiendo que el trabajo en equipo, la comunicación y la responsabilidad son importantes al crear software.

Busco oportunidades para seguir aprendiendo y adquirir experiencia como desarrollador. ¡Gracias por su tiempo! Me gustaría mostrarles mi proyecto.

## 3. Las cinco partes del pitch

| Parte | Frase o contenido |
|---|---|
| **Hook** | “Have you ever forgotten an important homework assignment or a school deadline?” |
| **Who I am** | “My name is Alejandro, and I am a high school student from Medellín, Colombia.” |
| **What I can do** | HTML, CSS, JavaScript, React, GitHub y aprendizaje de Supabase. |
| **Proof** | El proyecto RECORDATE, un sistema para organizar tareas y fechas académicas. |
| **Closing** | “I am looking for opportunities to keep learning and gain experience as a developer.” |

## 4. Vocabulario clave

- **Homework assignment:** tarea escolar.
- **Deadline:** fecha límite.
- **Web development:** desarrollo web.
- **User interface:** interfaz de usuario.
- **Database:** base de datos.
- **User authentication:** autenticación de usuarios.
- **Track changes:** registrar cambios.
- **Gain experience:** adquirir experiencia.

## 5. Plan para practicar

1. Lee el pitch en voz alta y marca las palabras que te cuesten pronunciar.
2. Practica por partes: hook, presentación, habilidades, proyecto y cierre.
3. No memorices cada palabra; recuerda la idea principal de cada sección.
4. Grábate y revisa si hablas con claridad y a un ritmo natural.
5. Usa un cronómetro. Si dura más de 95 segundos, elimina frases secundarias sin quitar las cinco partes principales.

**Nota:** presenta Supabase como una tecnología que estás aprendiendo y que está prevista para el proyecto, no como una función terminada si todavía no la has conectado.
